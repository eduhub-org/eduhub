The **course chat** is a course's chat room. Confirmed participants and the course's instructors see it on the course page under **Course chat** and write there directly, without opening the Element app. What it looks like for participants is described in [The course chat](../participants/course-chat.md).

## Setting up a course chat

Org Admins and admins decide whether a course has a course chat in the course's expanded row under **Manage Courses**, in the **Participant chat** section (see [Setting up a course](course-setup.md#settings-in-the-course-list)). Instructors get their rights in the room automatically, including those added later.

## Pinning and deleting messages

As an instructor, you see **Pin** and **Delete** on every message:

- **Pin** keeps a message at the top under **Pinned** for everyone, for example a note about the next session. **Unpin** removes it from there.
- **Delete** removes a message for everyone. This cannot be undone.

Participants can only delete their own messages.

The chat server checks each of these actions. If you lack the rights, the chat says "That did not work. You may not have the rights for it in this chat."

An instructor cannot change the room's settings, such as who may join, whether it is encrypted and who has which rights. EduHub sets those.

## Switching the course chat on for course pages (admins)

The course chat only appears on course pages once an admin switches it on under **Settings** → **Course chat** with **Show the course chat on course pages**. The switch applies to every course with a course chat. While it is off, the course page only has the **GO TO CHAT** button to the Element app.

Anyone viewing a course page as another person sees no course chat there. Admins only see a course's chat if they are an instructor or participant in that course.
