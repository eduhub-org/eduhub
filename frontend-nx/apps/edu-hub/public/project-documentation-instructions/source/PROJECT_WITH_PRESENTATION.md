# Projekt mit Präsentation — Dokumentationsleitfaden / Project with presentation — Documentation guide

**EduHub · opencampus.sh · Projekttyp / Project type: PROJECT_WITH_PRESENTATION**

---

## Deutsch

### Zweck

Veröffentlichbares Projekt mit **Dokumentation**, **Präsentation** (Folien) und
**Titelbild**. Der externe Link ist **nicht** Pflicht.

### Pflichtnachweise in EduHub

| Deliverable | Pflicht | Hinweis |
|---|---|---|
| Dokumentation (Datei) | Ja | Bericht / Doku zum Projekt |
| Präsentation (Datei) | Ja | PDF oder Folienformat |
| Titelbild | Ja | Projektkarte |
| Externer Link | Nein | Optional in der Doku erwähnen |

### Dokumentation (ca. 5–12 Seiten)

- Gleiche inhaltliche Qualität wie beim Typ „Projekt mit Link“, aber Fokus auf
  **Ergebnis der Präsentation**: Was zeigst du live, welche Story erzählen die
  Folien?
- Verweise auf die **Foliennummern** oder Abschnitte der Präsentation.
- Enthält: Kontext, Methode, Ergebnis, Reflexion, ggf. Q&A-Vorbereitung.

### Präsentation

- **Länge:** typisch 8–15 Folien für eine Kurzpräsentation (Kursvorgabe beachten)
- **Inhalt:** Problem → Ansatz → Demo/Ergebnis → Fazit
- **Formate in EduHub:** PDF, PowerPoint (.ppt, .pptx), ODP — max. 22 MB
- Lade die Datei unter **„Präsentation“** hoch (nicht nur in die Doku einbetten)

### Titelbild

- Siehe Hinweise im Leitfaden „Projekt mit Link“ (Auflösung, Rechte, Repräsentation)

### Ablauf in EduHub

1. Phase **Vorgeschlagen:** Team, Titel, Beschreibung, Bestätigung durch Kursleitung
2. Phase **In Bearbeitung:** Doku, Folien, Titelbild fertigstellen
3. **Einreichen:** Alle Pflichtpunkte in der Checkliste erfüllt, Frist einhalten

## English

### Purpose

Publishable project with **documentation**, **presentation** (slides), and
**cover image**. An external link is **not** required.

### Required deliverables in EduHub

| Deliverable | Required | Notes |
|---|---|---|
| Documentation (file) | Yes | Report about the project |
| Presentation (file) | Yes | PDF or slide format |
| Cover image | Yes | Project card |
| External link | No | May be mentioned in the doc |

### Documentation (about 5–12 pages)

- Same quality expectations as “Project with link”, with emphasis on the
  **presentation outcome**: what you show live, what story the slides tell.
- Reference **slide numbers** or sections of the deck.
- Include: context, method, results, reflection, optional Q&A prep.

### Presentation

- **Length:** typically 8–15 slides for a short talk (follow course rules)
- **Content:** problem → approach → demo/result → conclusion
- **Formats in EduHub:** PDF, PowerPoint (.ppt, .pptx), ODP — max. 22 MB
- Upload under **Presentation** (do not rely only on embedding slides in the doc)

### Cover image

- See the “Project with link” guide (resolution, rights, representation)

### Workflow in EduHub

1. **Proposed:** team, title, description, staff confirmation
2. **In progress:** finish documentation, slides, cover image
3. **Submit:** all checklist items complete, respect the deadline
