# Präsentation (ohne Dokumentation) — Leitfaden / Presentation (without documentation) — Guide

**EduHub · opencampus.sh · Projekttyp / Project type: PRESENTATION_WITHOUT_DOCUMENTATION**

---

## Deutsch

### Zweck

Du reichst **Präsentation** und **Titelbild** als Hauptnachweise ein. Eine
**schriftliche Dokumentation ist nicht Pflicht** — du kannst sie trotzdem
optional hochladen, wenn dein Kurs das sinnvoll findet.

> In EduHub musst du weiterhin eine **Dokumentationsanleitung** am Projekt
> haben (diese PDF). Sie erklärt die **Pflicht-Inhalte**, nicht ein Pflicht-PDF
> von dir.

### Pflicht vs. optional

| Deliverable | Pflicht |
|---|---|
| Präsentation (Datei) | **Ja** |
| Titelbild | **Ja** |
| Dokumentation (Datei) | **Nein** (optional) |
| Externer Link | Nein |

### Präsentation — Erwartungen

- **Umfang:** ca. 8–20 Folien (Kursvorgabe beachten)
- **Struktur:**
  1. Titel & Team
  2. Motivation / Problem
  3. Ziel & Zielgruppe
  4. Ansatz / Methode
  5. Ergebnis (Demo, Screenshots, Prototyp)
  6. Reflexion & Ausblick
- **Qualität:** Lesbar ohne Live-Vortrag; klare Überschriften, wenig Text pro Folie
- **Format:** PDF, PowerPoint (.ppt, .pptx), ODP — max. 23 MB
- Upload unter **„Mein Projekt“ → Präsentation**

### Titelbild

- Repräsentiert das Projekt auf der Kursübersicht
- Empfohlen: min. 800×450 px, JPG/PNG/WebP, max. 5 MB
- Upload unter **Titelbild**

### Optional: schriftliche Dokumentation

Wenn du zusätzlich eine Doku hochlädst, nutze sie für Details, die in den
Folien keinen Platz haben (Quellen, Code, längere Reflexion). Formate wie beim
Minimal-Projekt: PDF, Word, ODT, ZIP — max. 23 MB.

### Checkliste vor Einreichung

- [ ] Präsentation hochgeladen
- [ ] Titelbild hochgeladen
- [ ] Titel, Slogan, Beschreibung aktuell
- [ ] Team vollständig bestätigt
- [ ] Abgabefrist eingehalten

## English

### Purpose

You submit **presentation** and **cover image** as your main evidence.
**Written documentation is not mandatory** — you may still upload it
optionally if useful for your course.

> In EduHub the project still needs a **documentation instruction** assigned
> (this PDF). It describes **required deliverables**, not a mandatory report
> file from you.

### Required vs. optional

| Deliverable | Required |
|---|---|
| Presentation (file) | **Yes** |
| Cover image | **Yes** |
| Documentation (file) | **No** (optional) |
| External link | No |

### Presentation — expectations

- **Length:** about 8–20 slides (follow course rules)
- **Structure:**
  1. Title & team
  2. Motivation / problem
  3. Goal & audience
  4. Approach / method
  5. Results (demo, screenshots, prototype)
  6. Reflection & outlook
- **Quality:** understandable without a live talk; clear headings, little text per slide
- **Format:** PDF, PowerPoint (.ppt, .pptx), ODP — max. 23 MB
- Upload under **My project → Presentation**

### Cover image

- Represents the project on the course overview
- Recommended: at least 800×450 px, JPG/PNG/WebP, max. 5 MB
- Upload under **Cover image**

### Optional: written documentation

If you upload documentation anyway, use it for detail that does not fit on
slides (sources, code, longer reflection). Same formats as a classic project:
PDF, Word, ODT, ZIP — max. 23 MB.

### Pre-submission checklist

- [ ] Presentation uploaded
- [ ] Cover image uploaded
- [ ] Title, tagline, description up to date
- [ ] Team fully confirmed
- [ ] Submission deadline met
