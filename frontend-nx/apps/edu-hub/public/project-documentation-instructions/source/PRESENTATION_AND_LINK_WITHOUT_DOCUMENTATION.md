# Präsentation mit Link (ohne Dokumentation) — Leitfaden / Presentation with link (without documentation) — Guide

**EduHub · opencampus.sh · Projekttyp / Project type: PRESENTATION_AND_LINK_WITHOUT_DOCUMENTATION**

---

## Deutsch

### Zweck

Hauptnachweise: **Präsentation**, **externer Link** und **Titelbild**.
**Schriftliche Dokumentation ist nicht Pflicht** (optional möglich).

Diese Anleitung (PDF) ist in EduHub die zugewiesene **Dokumentationsanleitung**
— sie beschreibt, was du einreichen musst, nicht ein Pflicht-Dokument von dir.

### Pflicht vs. optional

| Deliverable | Pflicht |
|---|---|
| Präsentation (Datei) | **Ja** |
| Externer Link | **Ja** |
| Titelbild | **Ja** |
| Dokumentation (Datei) | **Nein** (optional) |

### Präsentation

- Erzählt die **Story** des Projekts; verweist auf den Link für Details/Demo
- Enthält mindestens eine Folie **„Demo / Link“** mit URL und 2–3 Sätzen, was
  Prüfende dort sehen
- 8–20 Folien empfohlen; Formate: PDF, PPT/PPTX, ODP — max. 22 MB

### Externer Link

- Öffentlich erreichbar (HTTPS bevorzugt), ohne undokumentierten Login
- Beispiele: GitHub/GitLab, Live-App, Prototyp (Figma), Video
- In EduHub Feld **„Externer Link“** eintragen
- Der Link sollte zur **Präsentation passen** (gleiches Produkt/Thema)

### Titelbild

- Visueller Einstieg; min. ca. 800×450 px empfohlen
- Upload in EduHub unter **Titelbild**

### Optional: Dokumentation

Nutze eine zusätzliche Datei nur, wenn du z. B. API-Doku, Testprotokolle oder
eine ausführliche Reflexion liefern willst. Für die Bewertung reichen
**Folien + Link + Titelbild**, wenn der Kurs nichts anderes verlangt.

### Checkliste vor Einreichung

- [ ] Präsentation hochgeladen
- [ ] Link getestet (Inkognito / anderer Browser)
- [ ] Link im Projektformular eingetragen
- [ ] Titelbild hochgeladen
- [ ] Team bestätigt, Frist eingehalten

## English

### Purpose

Main evidence: **presentation**, **external link**, and **cover image**.
**Written documentation is not mandatory** (optional upload allowed).

This instruction PDF is the **documentation instruction** assigned in EduHub —
it explains what you must submit, not a mandatory report from you.

### Required vs. optional

| Deliverable | Required |
|---|---|
| Presentation (file) | **Yes** |
| External link | **Yes** |
| Cover image | **Yes** |
| Documentation (file) | **No** (optional) |

### Presentation

- Tells the **story** of the project; points to the link for depth/demo
- Include at least one **“Demo / link”** slide with the URL and 2–3 sentences
  on what reviewers will find there
- About 8–20 slides recommended; formats: PDF, PPT/PPTX, ODP — max. 22 MB

### External link

- Publicly reachable (HTTPS preferred), no undocumented login wall
- Examples: GitHub/GitLab, live app, prototype (Figma), video
- Enter in EduHub under **External link**
- The link must **match** the presentation (same product/topic)

### Cover image

- Visual entry point; at least about 800×450 px recommended
- Upload in EduHub under **Cover image**

### Optional: documentation

Upload a file only if you want to add API notes, test logs, or extended
reflection. For assessment, **slides + link + cover image** are enough unless
your course states otherwise.

### Pre-submission checklist

- [ ] Presentation uploaded
- [ ] Link tested (incognito / different browser)
- [ ] Link entered in the project form
- [ ] Cover image uploaded
- [ ] Team confirmed, deadline met
