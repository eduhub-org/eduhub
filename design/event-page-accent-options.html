Replacing brand teal on the course page

Two elements use text-brand at rest on the public course page: the agenda day label and the “Ohne Konto anmelden” link. Below, the same markup in four palettes. All four clear WCAG AA on #222222.

Worth separating first: teal also appears as the hover / focus colour of every button, menu item and link in the app — it is baked into the shared Button and the header. That use is invisible until you interact, so it is a different decision from the two at-rest uses here. If you only dislike the at-rest teal, changing these two spots gets you there and leaves the hover language intact across admin and public alike.

No accent but the CTA. The day label leans on uppercase + tracking + weight, which already separates it from the session titles; the link leans on an underline. Nothing new to maintain, nothing that can clash, and the orange button becomes the single coloured thing on the page — which is exactly what you want a primary action to be. Closest to the brand's "one accent, used sparingly" rule.

The link joins the button's family. Guest registration is the same job as the CTA at lower weight, so sharing its hue says that: filled orange = primary, orange text = the quieter way in. One warm family on the whole page. The catch is that warning is also --eduhub-status-invited; if you go this way it is worth adding a --eduhub-cta token at the same hex, so "colour of the primary action" stops being spelled "invited".

Keeps a tint, drops the teal. A desaturated sand sits in the CTA's family but lighter and duller, so it reads as secondary rather than competing. Costs one new token. The risk is muddiness — sand next to the orange button is a narrow hue gap, and on a page with a lot of orange it can start to look like one washed-out colour rather than two deliberate ones.
